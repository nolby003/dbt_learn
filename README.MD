# dbt core

## Installing dbt and adapters

pip install dbt-core

pip install dbt-core dbt-postgres

pip install dbt-core dbt-redshift

pip install dbt-core dbt-bigquery

pip install dbt-core dbt-mysql

---
## Upgrading dbt and adapters

python -m pip install --upgrade dbt-core

python -m pip install --upgrade dbt-core dbt-postgres

python -m pip install --upgrade dbt-core dbt-redshift

python -m pip install --upgrade dbt-core dbt-bigquery

python -m pip install --upgrade dbt-core dbt-mysql
